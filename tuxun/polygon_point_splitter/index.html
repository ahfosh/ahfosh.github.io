使用说明

快速上手指南

1. 上传文件
  • GeoJSON：必须是 FeatureCollection，包含多个 Polygon 或 MultiPolygon 要素
  • 点数据 JSON：支持 {"customCoordinates": [...]} 结构，或普通数组。每个点需包含 lat / lng 字段
2. 配置与处理

选择用于文件命名的属性（推荐 name:en 获取英文名）。未匹配的点可单独保存。

3. 下载结果

处理完成后点击「下载 ZIP」，得到按多边形分割的多个 JSON 文件。

提示： 示例数据（中国省级边界 GeoJSON + 10,000 个百度全景点）已提供在对话附件中，可直接用于测试。
